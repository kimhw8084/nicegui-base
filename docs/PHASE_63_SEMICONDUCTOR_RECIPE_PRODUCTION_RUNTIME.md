# Phase 63 — Semiconductor Recipe Production Runtime & Smart Data Onboarding

Wave 63 closes the gap between Wave 62 recipe composition and a production-ready application starting point. It adds explainable schema onboarding, conservative auto-binding, provider-adapter hooks, governed per-recipe variants/customization, a bounded shared-state runtime, generated-project adapter/config boundaries, and agent guidance while preserving the Wave 59–62 architectural authorities.

Implementation authority is in `nicegui_base.semiconductor.onboarding`, `nicegui_base.semiconductor.variants`, `nicegui_base.semiconductor.runtime`, and the Wave 62 recipe factory. See `SEMICONDUCTOR_RUNTIME_ONBOARDING.md` for the engineering contract.
