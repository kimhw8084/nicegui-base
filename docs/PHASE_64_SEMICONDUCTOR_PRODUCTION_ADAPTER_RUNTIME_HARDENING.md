# Phase 64 — Semiconductor Production Adapter Conformance & Runtime Experience Hardening

Wave 64 turns the Wave 63 recipe runtime into a more production-defensible starting point. It adds bounded provider conformance, a first-class onboarding/setup model and renderer, standardized runtime experience state, runtime presets backed by existing snapshot persistence, bounded pushdown/performance probes, a target-environment certification object, and generated-project conformance/setup hooks.

The architectural authorities remain unchanged: Wave 59 `DataSource`, Wave 60 `AnalysisContext`/`SelectionBus`/workspace/persistence, Wave 61 semiconductor semantics/surfaces, Wave 62 recipe definitions, and Wave 63 onboarding/variant/runtime composition.

No new mandatory dependency is introduced. Installed NiceGUI, real server/WebSocket, supported corporate browsers, approved company adapters, representative fab-scale performance and current-source human visual baseline remain target-environment gates.
