# NiceGUI Base G2 Product Requirements

G2 extends the immutable D6H.3 Golden baseline without replacing its semantic authorities.

Core laws:

1. **Minimum click depth:** users must recognize visual capabilities from galleries without opening each detail page.
2. **Visual discovery:** components, analytics, patterns, recipes, layouts and full applications show useful previews when affordable.
3. **Full-width canvas:** normal reference/application surfaces use all usable width beside navigation with governed gutters.
4. **Grouped navigation:** Discover, Foundations, Compose, Semiconductor, Develop and System are distinct mental models.
5. **Context preservation:** search, family/filter, favorites, comparison and scroll survive normal exploration.
6. **Safe caching:** immutable catalog/sample/thumbnail work is build-bound; user/provider data is never put in shared preview caches.
7. **Bounded comparison:** compare up to three governed references inline rather than open/back repetition.
8. **No second registry:** the Explorer projects the existing canonical catalog and production renderers.
9. **Public API first:** detail Code surfaces teach stable consumer APIs, not Explorer harness internals.
10. **Semantic trust:** cached thumbnails are evidence-bound and labeled as thumbnails; current detail pages remain the live renderer authority.
11. **Responsive density:** phone/tablet prioritize content rather than stacking desktop controls verbatim.
12. **Qualification:** click efficiency, search latency, state restoration, package provenance, installed browser behavior and human visual review are release gates.
